Postmortem: checkout latency

SEV2 · 2026-10-09 · 47 minutes · blameless

Summary

Checkout p99 latency rose from 300 ms to 4 s after a deploy doubled the number of orders pods; the database connection pool ran out. The incident ended with a rollback; no orders were lost.

Timeline

  1. 14:02 Deploy of orders v1.42 (pods 12 → 24)
  2. 14:09 On-call paged: checkout latency alert
  3. 14:20 Tracing shows waits on database connections
  4. 14:38 Rollback; latency recovers
  5. 14:49 Incident closed

Action items

  • Size the connection pool per pod from the database limit (platform)
  • Add a saturation panel to the observability dashboards (platform)
  • Load test before scaling changes (ops)
